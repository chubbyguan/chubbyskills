# Chubby Skills 项目介绍

> 本文分两部分：**简介**可直接复制用于分享、投稿或聊天里介绍这个项目；**详细介绍**供想了解全貌的人阅读。

---

## 简介

**Chubby Skills 是一套把你散落在各个平台的内容，变成自己知识库的 Agent Skills 与命令行工具。**

刷到的视频、播客、公众号文章、推文，丢一个链接进去，就变成带来源、带时间、带原文的 Markdown，进你自己的文件夹。之后可以用关键词或语义搜索找到它，可以让 Agent 读着它帮你写作，也可以每天早上收到一份订阅源的日报。

14 个 Agent Skills 加一个 `chubby` 命令，核心流程**零第三方依赖**（Python 标准库即可跑通），转录在自己的电脑上完成，不经过任何服务器。视频优先抓字幕，命中就免去 GPU 和模型下载。

适合内容创作者、研究者，以及任何用 Markdown 或 Obsidian 攒素材的人。

---

## 详细介绍

### 一、它解决什么问题

绝大多数人收藏内容的方式，是把它丢进一个不会再看的地方：收藏夹、稍后读、聊天记录里发给自己的链接。收藏的动作很轻，代价是三个月后你只记得「好像看过」，找不到，也引用不了。

Chubby Skills 把「收藏」换成「入库」：素材落在你自己的磁盘上，是纯文本，带来源和时间，能被搜索，也能被 Agent 读取。**信息流会忘，知识库会记，Agent 会用。**

### 二、核心能力

**平台采集。** 把一个链接变成一份可检索的 Markdown —— 标题、作者、发布时间、互动数据和正文一并留下，而不是只剩一个网址。视频优先抓现成字幕，播客和其余视频落到本地转录，文章与图文走轻量路径，各自挑最省事的那条走。

**本地导入。** 已经在硬盘上的 Markdown、TXT 和带文字层的 PDF 可以直接入库，保留来源与附件关系，不联网也能用。

**知识库。** 素材入库即进索引，支持关键词检索和 semantic-lite 语义检索 —— 后者不需要外接向量数据库，也不调用任何嵌入服务。检索结果可导出成逐字原文资料包，带行号，方便引用与回查来源。

**订阅调度。** 消费公开的 RSS / Atom / JSON Feed 与 YouTube 频道，去重、聚簇、按热度排序，产出每日情报简报；也可以渲染成纯静态日报站发到 GitHub Pages。

**MCP 服务。** 知识库可作为一个 MCP server 接给 Agent，让它在动手之前先读你已有的素材，而不是凭空生成。

### 三、Skill 目录

**视频转录** — B站、YouTube、抖音、TikTok、微博、知乎。字幕优先，命中字幕时不需要 GPU、不需要下载模型。

**播客转录** — 单集、RSS、本地音频。默认跑本地的 SenseVoice-Small，中文标点与数字处理较好；可选 DashScope / Groq 云端后端（更快，需自备 Key）。

**图文采集** — 公众号文章与 PDF、X/Twitter 正文与长文章（支持登录态抓全文）。这两条走 Python 标准库，零依赖。

**加工与整理** — 摘要、要点、标签；学习笔记自动化（知识点提取、闪卡、知识图谱）；行业情报雷达（多源扫描 → 关键词过滤 → 趋势检测 → 每日简报）。

**知识库管理** — 入库、健康检查、索引、检索、资料包导出、归档，以及 MCP 连接。

### 四、典型工作流

```bash
# 1. 建一个知识库
python3 tools/chubby.py init --vault ./vault

# 2. 采集一条真实链接（只用一个链接就能跑通，无需装任何包）
python3 tools/chubby.py ingest "https://x.com/example/status/123456"

# 3. 导入自己的文件
python3 tools/chubby.py import ~/notes/读书笔记.md

# 4. 写作前先搜证据
python3 tools/chubby.py search "内容策略"

# 5. 导出一份带原文行号的资料包
python3 tools/chubby.py brief --topic "内容策略" --output brief.md
```

把第 2 步的链接换成任意支持的平台即可；采集入库后索引会自动更新。

### 五、几个刻意的技术取舍

**字幕优先，而不是默认转录。** YouTube 与 B站的官方字幕质量足够且完全免费，命中字幕时整条链路不需要 GPU、不需要下载 2GB 模型。只有拿不到字幕时，才落到本地转录。

**核心流程零依赖。** `chubby` 命令、图文采集、知识库索引与检索全部只用 Python 标准库。重依赖（funasr、ffmpeg、torch）只在真正需要视频转录时按需安装，`setup.sh` 会告诉你缺什么、怎么装。

**转录跑在本地。** 默认用本机 CPU 跑 SenseVoice-Small，音频不出你的电脑。想更快可以显式选云端后端，但那是你的选择，不是默认。

**Skill 是可搬移的目录。** `install_skill.py` 会把公共模块打包进每个技能目录，装完就能单独搬走，不依赖原始仓库，也不需要在 Agent 根目录维护共享模块。

**发布内容有硬边界。** 订阅日报站只发布标题、来源、时间、原始链接和热度，**绝不包含正文、本地路径或相关笔记标题**；这条边界由测试强制保证，防止不小心把私人笔记发到公网。

### 六、上手

```bash
git clone https://github.com/chubbyguan/chubbyskills.git
cd chubbyskills
bash setup.sh                                   # 只检查环境，不装任何包

python3 tools/install_skill.py --list           # 看有哪些 skill
python3 tools/install_skill.py --all --dest ~/.claude/skills
```

也可以先不装 skill，直接用命令行跑通采集 → 入库 → 搜索的完整链条。

详细安装路径见 [安装指南](./installation.md)，各平台能力与失败模式见 [平台状态](./platform-status.md)。

### 七、边界

- **不做账号扫描。** X、抖音、B站、公众号的「自动扫我关注的人」不在支持范围；订阅系统只消费有稳定 Feed URL 的内容源。
- **不绕过平台风控。** 走平台公开字幕、RSS、嵌入端点，以及用户自己浏览器里的登录态。处理的是你有权访问的内容，定位是个人学习与研究。
- **不保证所有平台都在线验收。** 各平台的验证程度不同，README 与平台状态页会明确区分「声明支持」「离线可复现」「在线已验收」三种状态，不混为一谈。
